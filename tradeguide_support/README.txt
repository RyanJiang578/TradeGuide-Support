TradeGuide support page — GitHub Pages setup

1. Open index.html in a text editor.
2. Replace YOUR_SUPPORT_EMAIL@example.com with an inbox you monitor.
3. Create a PUBLIC GitHub repository, for example TradeGuide-Support.
4. Upload index.html into the repository root (not inside another folder).
5. In repository Settings > Pages, under Build and deployment choose Deploy from a branch, main, / (root). Save.
6. Open the published URL and verify FAQs, contact address, and mobile layout.
7. Paste the VERIFIED URL into App Store Connect > TradeGuide > Support URL.

Example URL after publishing (not a live link until configured):
https://ryanjiang578.github.io/TradeGuide-Support/

IMPORTANT:
- Support URL and Privacy Policy URL are separate App Store Connect requirements.
- This package does NOT include a Privacy Policy page.
- An email-based account-deletion request is not a substitute for Apple's in-app account deletion requirement.
- Review the FAQs and make sure they match your released app before publishing.
